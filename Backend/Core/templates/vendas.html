Perguntas Frequentes

Preciso de cartão de crédito para testar?

Não. Oferecemos 7 dias grátis sem necessidade de cartão. Apenas preencha o formulário e começe a usar.

O sistema é multi-tenant?

Sim! O SGO suporta múltiplas lojas/empresas com dados completamente isolados, ideal para franquias ou grupos.

Posso cancelar a qualquer momento?

Sim. Você pode cancelar sua assinatura a qualquer momento, sem multa ou burocracia.

O sistema tem integração com WhatsApp?

Sim! O SGO possui integração com Evolution API para enviar notificações automáticas aos clientes.
